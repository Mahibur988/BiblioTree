# BiblioTree 📚🌳

BiblioTree is a C++ project that simulates a free library system using a Binary Search Tree (BST).  
It reads a tab-separated inventory of books and organizes them alphabetically by title for efficient storage and retrieval.

## 🚀 Features
- Reads book data from a file (TSV format)
- Stores books in a Binary Search Tree (BST)
- Automatically sorts books alphabetically by title
- Extracts and separates author first and last names
- Supports searching and displaying book records

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- Binary Search Trees (BST)
- File I/O in C++
- String parsing and manipulation
